FOR DEEPSEEK HARNESS WEB

每一次调用，
都有迹可循。

DSH Usage Stats 是 DeepSeek Harness Web 的本地用量中心。统一查看 Token、账户余额、套餐额度和费用趋势，数据与配置留在本机。

开始安装 ↓查看源码 ↗

需要 DeepSeek Harness dsh-v0.1.1-rc.2 或更新版本，以及 Node.js 18+

LOCAL-FIRST OBSERVABILITY

统计留在本机。
视野保持清醒。

⌄
01

调用、成本与趋势

今日、本月、累计 Token、请求次数、模型拆分、24 小时趋势与年度热图。DeepSeek 调用按完成时间冻结费用。

02

多供应商账户

DeepSeek、Moonshot、OpenRouter、Kimi、MiniMax、Z.ai 等已配置 provider 的余额、套餐窗口与 Token 数据统一呈现。

03

有分寸的限制

配置消费限额、余额提醒与预警比例。仅在你显式开启时才会拦截新的模型调用。

04

数据留在本机

统计账本、设置与告警保存在本机；凭据只通过 Harness 服务端解析。

PRODUCT TOUR

运行的一切，

GET STARTED

让你的 Harness
从现在开始可见。

01 在插件目录的父目录执行

dsh plugin --profile web add ./dsh-usage-stats

02 或直接从 npm 安装

dsh plugin --profile web add @wannanbigpig/dsh-usage-stats
